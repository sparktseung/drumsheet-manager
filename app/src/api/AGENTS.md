# API Client — Agent Guide

> **Parent**: [../AGENTS.md](../AGENTS.md) — frontend source

## Files

- [client.ts](client.ts) — All backend API calls and type re-exports.

## Exports

| Export | Kind | Description |
|--------|------|-------------|
| `API_BASE_URL` | const | Resolved from `VITE_API_BASE_URL` env, falls back to `http://[IP_ADDRESS]:8000` |
| `SongRow` | type | Re-exported from generated OpenAPI types |
| `SongCount` | type | Re-exported from generated OpenAPI types |
| `SyncJob` | type | Re-exported from generated OpenAPI types |
| `SongViewMode` | type | `"playable" \| "unplayable"` |
| `fetchSongs()` | function | GET `/songs/playable` or `/songs/unplayable` with pagination + search |
| `fetchRandomPlayableSong()` | function | GET `/songs/playable/random` |
| `fetchSongsCount()` | function | GET `/songs/playable/count` or `/songs/unplayable/count` |
| `fetchSong()` | function | GET `/songs/{songId}` |
| `startSyncJob()` | function | POST `/admin/sync` |
| `getCurrentSyncJob()` | function | GET `/admin/sync/current` |
| `getSyncJobStatus()` | function | GET `/admin/sync/{jobId}` |

## Key patterns

- All requests go through `requestJson<T>()` which adds `Content-Type: application/json` and throws on non-OK responses.
- `buildUrl()` strips trailing slashes from `API_BASE_URL` and appends query params.
- Types are generated by `openapi-typescript` from the backend's `/openapi.json` and stored in [../generated/openapi-types.ts](../generated/openapi-types.ts).
